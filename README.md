# Rheizor releases

Download builds of **Rheizor**, a modular UI suite for **WoW Forever**: `Rheizor-Core` (required) plus one addon per feature, all configured in game with `/rz`.

## Install or update (recommended)

1. Download **[Update Rheizor.bat](https://raw.githubusercontent.com/jaimesares/rheizor-ui-releases/main/Update%20Rheizor.bat)** (right-click → *Save link as…*).
2. Put it inside your game's `Interface\AddOns` folder, for example `World of Warcraft\_classic_\Interface\AddOns`.
3. Double-click it whenever you want to update. It checks the latest version and, if yours is older, downloads it and replaces only the `Rheizor-*` folders. Your other addons and your settings (the `WTF` folder) are never touched.
4. Restart the game completely, log in and type `/rz`.

Windows may warn you the first time you run the `.bat` ("Windows protected your PC"). Click *More info* → *Run anyway*.

## Install by hand

1. Download the newest zip from the [`releases`](releases) folder. The current version is in [`latest.txt`](latest.txt).
2. Unzip it inside `Interface\AddOns`, replacing the existing `Rheizor-*` folders.
3. Restart the game completely and type `/rz`.
